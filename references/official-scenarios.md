# 公文案件場景補充指引

本指引補足「知道文別，仍不知道案件怎麼寫」的情況。先依政府公文規範決定行文方向、簽辦方式及欄位，再讀取命中的場景。下列「骨架」是撰寫提示；定型化表單應優先使用機關現行格式，不把提示欄位宣稱為法定統一格式。

## 場景索引

| 編號 | 使用者常見說法 | 選用與閱讀重點 |
|------|----------------|----------------|
| S01 | 還沒回、催報、催繳 | 催辦案件通知單；新增要求時再評估函 |
| S02 | 來不及、申請展期、延長處理 | 區分機關請求展期、機關通知人民延長、人民申請展期 |
| S03 | 資料不齊、限期補件 | 補正通知；查明補正依據及逾期效果 |
| S04 | 不符資格、駁回、部分同意 | 函或專用處分書；先判斷是否行政處分 |
| S05 | 裁罰前讓對方說明 | 陳述意見通知；與補正、裁處書分開 |
| S06 | 回覆民眾陳情、非本機關權責 | 逐點答復、移轉及告知；移文單可簡化作業 |
| S07 | 已發文打錯、漏附件、原函作廢 | 區分文稿修訂、已發文更正與實質變更處分 |
| S08 | 會辦主計、請法制表示意見 | 便簽或簽稿送會；主辦與會辦各自提出具體意見 |
| S09 | 到現場會勘、勘查紀錄 | 會勘通知單與紀錄分開，保留實際觀察與未決事項 |
| S10 | 會議延期、取消、決議追蹤 | 異動通知、紀錄核定與追蹤表，確認目前階段 |
| S11 | 以個人名義洽商公務 | 箋函；不限定首長，也不套機關函的行款 |
| S12 | 剛才電話講好了、留個紀錄 | 公務電話紀錄；區分實際通話與待辦事項 |

## 共通判斷

- 從現有資訊辨識「誰對誰、目前辦到哪裡、希望對方做什麼」。已提供的身分、原文、日期及核定情形不重問。
- 必須區分草稿、已核定未發文、已發文及已送達；「擬同意」不能改寫成「業經核准」。
- 缺少會改變處理結論的資訊（例如否准依據、補正效果、期限起算點）時先詢問。使用者要先看草稿，可用「〔待確認：……〕」明示待補；不得編造法條、核定結果、發文字號或送達日期。
- 有法定或機關專用表單時，將已知內容填入該表單。參考格式、慣用寫法、法律要求應分清楚。

## S01 催辦、催復、催報

**先確認**：原發文日期字號、原期限、尚未完成項目、是否已收到回覆，以及本次是否新增要求或改變期限。

已行文且逾期未復，依文書處理手冊第45點第1款用催辦案件通知單。未屆期的提醒不寫成「逾期未復」；如要新增實質要求、處理爭議或作成處分，應重新判斷文別與依據。

填寫骨架：催辦機關／受催機關 → 原文日期字號及案由 → 原期限與未復事項 → 本次催辦內容、回復方式及聯絡人。依機關表單填列；另用函且訂有辦理期限時，將期限敘明於主旨。

催辦不等於自動准予展期。原期限與本次要求的回復時間分別列明，不杜撰「逾期即處罰」或新的法定效果。

## S02 展期申請與延長處理通知

**先確認**：誰要求延長、期限來源（來文、法規、機關公告或契約）、原截止日、已辦進度、具體原因、所需延長時間及核准狀態。

| 情況 | 撰寫方式 |
|------|------------|
| 本機關請求來文機關延長填報期限 | 依權責先簽或擬函；敘明原期限、已完成事項、阻礙、預計完成日及補救安排。尚待核准時寫「擬申請展延至……」，不寫「業經展延」 |
| 機關延長人民依法規申請案件的處理期間 | 查明特別規定及公告處理期間；適用行政程序法第51條時，依其延長長度、次數及通知時點規定辦理，不套用陳情的30日規則 |
| 機關延長陳情案件處理 | 依適用的陳情作業規定簽准並通知理由；行政院及所屬機關另依陳情要點第11點。地方機關應查自己的適用規定 |
| 民眾請求延長補件、繳納或履行期限 | 轉入人民對政府文書的申請書；確認該期限能否延長，不保證提出申請即停止原期限 |

函稿內容順序：原案 → 延長原因與辦理進度 → 申請或通知的新期限及後續作法。對上級機關用「請鑒核」，內部請示用「請核示」。

## S03 補正／補件通知

**先確認**：申請案與收件資料、欠缺項目及其依據、能否補正、補正期限及起算方式、收件管道、逾期效果。

補正通知應讓收件人知道具體缺什麼、如何補。依案件程序選函或機關專用通知書；不能只因篇幅短就判為書函。

建議逐項整理：

| 待補正項目 | 已交資料的欠缺 | 依據及應補內容 |
|------------|----------------|----------------|
| 〔項目〕 | 〔具體欠缺〕 | 〔適用條款／表單要求與可接受形式〕 |

主旨敘明案由及補正期限；說明交代原申請、上述缺漏、補正方式與經查證的逾期效果。「文到○日內」「送達次日起○日內」及指定日期不能任意互換；不得憑一般經驗一律給7日、10日或30日。法規未查明時，不擅寫「逾期視同撤回」「不再通知逕予駁回」。

缺少證明文件的補正，與裁罰前聽取意見是不同程序，後者讀 S05。

## S04 否准、部分准許與附條件核准

**先確認**：申請內容、審查事實及證據、適用依據、補正經過、擬准駁範圍、有無裁量或附款、核決狀態。

先看內容是否對外直接發生法律效果，再決定是否屬行政處分；文件名稱叫「函」也可能是處分。採函或專用處分書時，均應依適用法規備齊處分內容、事實、理由、法令依據及救濟教示等事項（行政程序法第96條；例外另查適用規定）。

內容骨架：

1. 清楚列出准許與不予准許的範圍。
2. 將每個不符要件對應至已查明的事實及依據，不能只寫「歉難照准」。
3. 部分准許、附條件或要求履行義務時，確認權限、依據及範圍，不自行增加條件。
4. 查明該案的救濟方法、期間與受理機關，再寫教示；不可不分案件一律貼「30日內訴願」。

機關內部尚在簽辦時寫「擬不予同意」，不預先當成已作成、已送達的處分。單純洽詢答復也不應為了格式完整而加上處分教示。

## S05 作成不利處分前的陳述意見通知

**先確認**：擬作成的處分、原因事實及證據、法規依據、當事人、是否已給陳述機會或有法定例外，以及陳述期限與方式。

依行政程序法第102–106條及案件特別規定判斷。需要通知陳述時，書面內容應包含相對人及地址、擬處分的原因事實與依據、得提出陳述書的意旨、期限及未提出的效果，並提供實際可用的提出方式。使用機關專用通知書或函，不直接套裁處書。

以「本案擬……，請就下列事項陳述意見」表達程序階段，不能將尚待判斷的事實寫成最終裁罰結論。依第105條，未於期間內提出陳述書是放棄陳述機會，**不是承認違規**。期限及特別法效果均須查明，不自行設定固定天數。

## S06 人民陳情答復與移轉

**先確認**：具體訴求、收件日期或案件編號、權責歸屬、已查證事實、現有處理結果及尚待辦事項。

- **本機關權責**：逐點對應「陳情事項 → 查處結果 → 處理理由及依據 → 後續措施」。尚在調查就說明進度，不將「已轉承辦」當成完成答復。
- **非本機關權責**：查明受移送機關後移送並通知當事人（行政程序法第17條；陳情另依適用作業規定）。單純移送可依手冊第45點第2款採移文單，不必固定寫書函。骨架為原收文日期字號、案由、移送理由、受移送機關、隨送資料及通知對象；不要只退件叫民眾自行重送。
- **跨機關案件**：分清本機關可答復部分及移送部分，說明由誰接續處理，不把「副本給另一機關」當成已完成移送或協調。

答復方式依案件性質及機關規定，可為公文、電子郵件或其他適當方式。寫公文時，無涉准駁解釋的單純聯繫可採書函；具有處分性質者回 S04。行政院及所屬機關依陳情要點第10點，答復須具體易懂並副知有關機關。

民眾只是想反映問題時，仍走陳情書；如請求改變既有處分，應辨識法定救濟程序，不暗示再寄陳情書會停止救濟期間。

## S07 原函更正、補送附件與實質變更

**先確認**：文件是否已發出或送達、原日期字號、錯誤位置、正確資料的來源、影響範圍、原收件人及附件版本。

| 問題 | 處理與寫作重點 |
|------|----------------|
| 尚未發出的稿件筆誤 | 直接修稿並依機關流程再核；不另寫一封不存在的「更正函」 |
| 已發的一般通知文字錯誤 | 指明原文與更正位置，列出「原列／更正為」，依機關程序通知受影響收件人；其餘內容是否維持須先確認 |
| 漏附或附錯附件 | 寫清楚補送或替換的附件名稱、數量、版本及適用範圍；不能只寫「附件抽換」而未識別是哪一份 |
| 行政處分的誤寫、誤算等顯然錯誤 | 適用行政程序法第101條時，依規定附記或製作更正書並通知，不只偷偷改檔 |
| 撤回核准、改變權利義務、撤銷或廢止處分 | 先查明實體及程序依據，依權限另行簽辦；不能用「原函作廢」或第101條替代 |

更正骨架：「有關本機關○年○月○日○字第○號函〔位置〕，原列『〔原文〕』更正為『〔正確內容〕』，請查照。」須依行文方向調整期望語；這是一般通知的寫作示意，不是所有行政處分更正的完整格式。

## S08 便簽、送會與會辦意見

**先確認**：主辦／會辦身分、對方是同機關單位或另一機關、會辦範圍、待決爭點、相關資料及處理期限。

便簽以單位名義洽復公務（手冊第15點），內部書面洽辦也可依第44點第4款採書函或原文分送會簽。已有原簽可送會時，不必為每一單位另造一封機關函。跨機關會商、簽稿送會與會銜依第29點選擇；**會辦、列副本及會銜不是同一件事**，不能因請對方表示意見就並列機關名稱聯合發文。

便簽內容骨架（行款依機關現行格式）：

```
〔單位名稱〕便簽
致：〔受洽單位〕
一、〔案由、原簽或資料的識別資訊〕。
二、〔請對方就哪一項職掌、條文或金額表示意見〕。
三、〔回復期限及方式；附件名稱與數量〕。
〔承辦／單位主管簽章及日期，依機關規定〕
```

會辦方回應順序為「審閱範圍 → 具體意見及依據 → 建議修改或待補資料」。無意見只表示就本單位職掌及所送資料未有補充，不等同代表全案合法或代主辦核准。主辦方彙整時列明採納情形；歧見未解者呈現選項及建議，不改寫成「各單位均同意」。

## S09 會勘通知與會勘紀錄

**先確認**：會勘目的、標的及位置、時間、集合地點、主持／聯絡人、出列席人員、攜帶資料，以及是否已完成會勘。

通知依手冊附件1「通知單」格式使用「會勘事由／時間／地點」等欄位，沿用開會通知單的受文者、發文資料、附件、出列席者、副本及備註。現場與集合地點不同時分列；必要時附位置圖，不只寫模糊地名。

紀錄骨架：「會勘時間地點與人員 → 案由 → 現場實際情形 → 各單位意見 → 結論、分工及期限 → 照片或圖說附件」。此為工作紀錄建議，特定業務的勘驗表單優先。

將目視觀察、當事人說法與待查事項分開。未到場、未測量或未形成結論的內容不得補寫成已確認事實；會勘紀錄本身不當然代替許可或裁處。

## S10 會議異動、紀錄更正與決議追蹤

**先確認階段**：尚未開會的異動、會後未核定紀錄、已核定紀錄更正，或既有決議的執行追蹤。

- **改期／取消**：沿用機關通知方式，交代原通知日期字號、會議名稱、原時間及變更項目；通知原出席者、列席者及需要知悉的單位。新時間未定就寫「另行通知」，不編造日期。
- **會議紀錄**：只根據實際會議資料整理；建議、個別發言與主席結論／決議分開。尚未核定者標示草稿及待核定狀態。
- **紀錄更正**：指明原紀錄的案次、原文、更正內容及查證依據，依會議或機關程序確認。不同意原決議應循提案或變更決議程序，不以「潤飾」偷改既有決議。
- **追蹤辦理**：可整理「案次／決議摘要／主辦及協辦／期限／目前進度／待解決問題」。只填已知進度，未提供者標待確認；不能見到「持續辦理」就判結案。

以上為寫作與版本辨識建議；議事規則、法定會議程序及機關格式優先。

## S11 箋函洽復公務

**先確認**：以誰的個人名義、對方稱謂、洽商或回復的公務內容，以及是否其實需要機關正式核准或意思表示。

手冊第15點所稱箋函是以個人名義洽復公務，不限首長，也不限慶賀致謝。私人書信、商業 email 仍不屬本 skill 的範圍；涉及機關權限的決定則應回到正式簽函程序。

依手冊附錄5及機關慣用格式，以稱謂啟事、本文、結尾敬語、署名及日期組成，不硬套主旨／說明／辦法與正副本欄：

```
〔收信人適當稱謂〕：

〔洽商緣由或回復的來函事項〕。
〔具體請託、答復及必要的後續聯繫安排〕。

〔適當結尾敬語〕
〔具名人署名〕
中華民國○年○月○日
```

只使用具名人已確認的意思，不代為承諾尚未核定的資源或政策。

## S12 公務電話紀錄

**先確認**：已發生的通話時間、發話與受話人的單位／職稱／姓名、通話摘要、確認事項、待辦分工，以及是否需送對方確認。

使用手冊附件2或機關表單，填入通話時間、雙方資料、通話內容、協調事項及紀錄人等相應欄位。摘要宜區分「對方表示」「我方答復」「雙方確認」「尚待確認」；未說過的話、未取得的同意不能補入。

必要時依手冊第15點製作2份，送對方簽收並雙方附卷。電話紀錄不當然替代應以書面作成或依法送達的文件；主管電話交辦涉及後續核定者，仍按權責簽辦。

## 場景品質檢核

交付前核對：選用的是正確程序與文別？原案及版本可辨識？主體與核定階段一致？期限來源與起算清楚？准駁或逾期效果有依據？應通知的人與待辦事項完整？摘要是否忠於提供的事實？

對會議紀錄、箋函、電話紀錄等套用其自身結構，不強制加入函的主旨或期望語。對函稿則併用政府公文規範的用語與行款檢核。
