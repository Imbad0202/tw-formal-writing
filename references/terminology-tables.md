# 公文用語詳細對照表

本文件收錄公文用語的完整對照表，供撰寫時查閱。`official-letter.md` 已包含最常用的用語，此處提供更完整的補充。

## 一、引敘語完整對照

### 文句前端（開頭引述來文時）

| 用語 | 使用時機 | 範例 |
|------|----------|------|
| 奉 | 引敘上級機關或首長來文 | 「**奉**鈞長指示辦理公文訓練一案……」 |
| 准 | 引敘主管機關之規定或說明 | 「本案可否辦理留職停薪，**經函准**銓敘部解釋略以……」 |
| 據 | 引敘平行、下級機關或人民來文 | 「**據**本市各區公所查報結果……」 |

### 文句末端（引述完畢時）

| 用語 | 使用時機 |
|------|----------|
| 奉悉 | 回復上級機關來文或首長指示，於引敘完畢時使用 |
| 敬悉 | 回復平行機關來文，於引敘完畢時使用 |
| 已悉 | 回復下級機關公文，於引敘完畢時使用 |

### 表明依據

| 用語 | 使用時機 |
|------|----------|
| 遵照 | 對直屬上級機關表明依據 |
| 依照 | 對主管機關表明依據 |
| 依據、依照、根據 | 對平行、下級機關或屬員、人民來文時使用 |

> 「依」「依據」為現行通用引據語，上行、平行、下行文均可使用；手冊並無「上行文應使用『依』而非『依據』」之規範（院長信箱釋例 108.7.24）。上表方向區分屬傳統慣用，供選用時參考。

### 並列連接詞「及／與／暨」（立法院函頒「立法慣用語詞」）

- 僅 1 個連接處：用「**及**」——甲及乙
- 2 個以上連接處：上用「**與**」、下用「**及**」——甲與乙及丙；或頓號並列——甲、乙及丙；甲、乙、丙及丁
- 「**暨**」不作一般連接詞，僅用於標題、專有名詞或較正式隆重之場合（如「○○研討會暨頒獎典禮」「資訊管理暨工程學系」）
- 並列行政區劃用括號式：「縣（市）政府」「鄉（鎮、市、區）公所」「省（市）政府」，不寫「縣市政府」「鄉、鎮公所」

## 十一、法律統一用語表（立法院 62.3.13 認可）

| 統一用語 | 說明 |
|------|------|
| 「設」機關 | 如「教育部組織法」：教育部**設**文化局 |
| 「置」人員 | 如「司法院組織法」：司法院**置**秘書長一人 |
| 「第九十八條」 | 法律條文序數不寫「第九八條」；「第一百條」不寫「第一００條」；「第一百十八條」不寫「第一百一十八條」 |
| 「自公布日施行」 | 不寫「自公佈之日施行」 |
| 「處」五年以下有期徒刑 | 自由刑用「處」，不用「科」 |
| 「科」五千元以下罰金 | 罰金用「科」，且不寫「科五千元以下**之**罰金」 |
| 「處」五千元以下罰鍰 | 罰鍰用「處」，且不寫「處五千元以下**之**罰鍰」 |
| 準用「第○條」 | 引用本法其他條文，不寫「本法第○條」 |
| 「第二項」之未遂犯罰之 | 引用本條其他項，不寫「本條第○項」 |

## 十二、常見疑義字組（依教育部重編國語辭典釋義及院長信箱釋例整理）

| 字組 | 區分 | 例 |
|------|------|------|
| 需／須 | 「需」＝一定要**有**（need），下接名詞：必需品、需才、不時之需；「須」＝一定要**做**（must），下接動詞：須知、亟須、務須 | 需要＝要有；須要＝要做 |
| 做／作 | 「做」指具體之製造興辦：做事；「作」指抽象：作業、作為、作法、作成 | — |
| 周／週 | 「周」＝完整、完全：周全、周知、周到、周圍；「週」＝循環：週年、週期、週轉、一週 | 公告「周知」用周 |
| 察／查 | 「察」＝仔細觀看考核：洞察、觀察、明察暗訪；「查」＝檢查查驗：查報、查證、查辦、復查 | 偵查＝法律術語；偵察＝軍事術語 |
| 復／覆 | 「答復」「答覆」均可（均為現行法令用字，「公文程式條例」用答復、「行政程序法」用答覆；院長信箱釋例 104.7.29），實務慣用「復」：函復、回復、請惠復 | 不必把「回覆」硬判為錯字，但公文以「復」為慣用 |
